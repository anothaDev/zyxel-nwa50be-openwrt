# v0.1.0 draft

Source-only candidate for NWA50BE patches, per-device build tooling,
installation documentation, and validation evidence.

No binary assets are attached. Public binary release is blocked by per-device
calibration and unresolved Qualcomm firmware redistribution terms.

Security hardening in the candidate build includes uHTTPd's August 2026 fixes,
OpenSSL 3.5.8, the cgi-io fix for CVE-2026-62947, removal of LuCI's stale mount
ACL crontab grant, LuCI DHCP lease escaping, the uMDNS fix for CVE-2026-55492,
no default root password, removal of the unused odhcpd server variants affected
by CVE-2026-62948, HTTPS-only management, wireless-to-management filtering, a
trusted management allowlist, and disabled remote package feeds. OpenSSL QUIC
support is excluded because no shipped service uses it, removing the
CVE-2026-14456 listener attack surface.
Provisioned upgrades preserve key-only SSH and HTTPS LuCI while restricting
both services to the recorded wired administrator `/32`. Because the pinned
OpenWrt snapshot treats plain `sysupgrade <image>` as no-preservation, the
project ships a fail-closed wrapper that creates and verifies a backup before
passing it explicitly with `sysupgrade -f`.

The first hardened-image installation exposed that CLI semantic and required a
verified UART configuration restore. The recovered AP subsequently passed a
normal reboot, 2.5 GbE, management, HTTPS-only, and multi-BSS acceptance checks.

A 2026-08-28 read-only checkpoint recorded more than five days of uninterrupted
uptime, all three BSSes active, zero Ethernet hardware error/drop counters, no
retained radio-crash or link-down event, and 20/20 successful routed management
probes. The nonzero Linux `rx_dropped` aggregate remained unchanged during the
sample and is documented without attributing an unverified cause.

The audit findings, mitigations, and distinction between live-verified and
artifact-only changes are documented in `docs/SECURITY.md`.

A clean 2026-08-28 build passed prepared-source, artifact, and security
regression verification with the documented uHTTPd, OpenSSL, cgi-io, uMDNS,
and LuCI corrections. The resulting device-specific artifact remains
private, unpublished, and unflashed; this candidate release contains source
only.
